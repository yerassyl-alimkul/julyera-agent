# JulYera Agent: новый мобильный дизайн (спецификация передачи)

Холст с макетами: https://claude.ai/artifact/LiwsE2Has4x3DXPqPaUgdU (12 экранов, часть кликабельна).
Точные значения (отступы, цвета, размеры) лежат в `reference/*.dc.html`. Это обычный HTML с inline-стилями
и маленьким скриптом для демонстрации. Теги `<x-dc>`, `<sc-for>`, `<sc-if>` и `{{...}}` копировать не нужно,
бери из них только числа и разметку.

## Как работать с этим файлом

- Цель: заменить внешний вид и раскладку `web/index.html` для телефона. Логику, API и данные не менять.
- Что уже есть в коде и должно остаться: `loadTasks` (опрос каждые 15 с), `dateKey`, `parseNaiveDeadline`,
  `fmtDeadline`, `deleteTask` с `pendingDeletions` (отмена 5 с), `saveEdit`, подзадачи (`toggleSubtask`,
  `addSubtask`, `deleteSubtask`), заметки, `downloadCSV`, `openPrintView`, `setupVoiceInput`, `checkGoogleStatus`.
- Сначала предложи план работ и жди подтверждения, затем делай по шагам из раздела 11.
- В конце раздела 12 перечислены решения, которые я не принимал за владельца. Не угадывай их, спроси.

## 5. Поведение и взаимодействия

**Полоса дней и список (`Main`)**

- Группировка по ключу `dateKey(task.deadline)`. Считаются только задачи не в статусе Done.
- Первый чип «Без даты»: задачи, у которых `deadline` равен null. Дальше дни по возрастанию.
- При открытии выбран сегодняшний день, он прокручивается в видимую область. Если задач на сегодня нет, показывается пустое состояние «На этот день задач нет».
- Число в чипе: количество задач дня. Нет задач: число не показывается.
- Подзаголовок: «Сегодня · 6 октября · 5 задач» (слово «Сегодня» только для текущего дня).
- Чекбокс: `PATCH /tasks/{id}` со статусом Done, строка исчезает со списка, задача уходит в архив. Для повторяющихся задач следующая создаётся на бэкенде.
- Тап по строке (вне чекбокса и шеврона) открывает `Edit`. Шеврон раскрывает или сворачивает шаги и теги.
- Свайп влево по строке: открывает действия шириной 140 px, строка следует за пальцем, фиксируется на 180 мс. Полного свайпа «до конца» для удаления нет, чтобы не удалять случайно. Тап вне строки закрывает действия.
- Удаление: строка убирается сразу, показывается уведомление «Задача удалена · Отменить» на 5 секунд, `DELETE` уходит по истечении времени. Это уже реализовано как `pendingDeletions`, нужно только перерисовать уведомление.

**Изменение (`Edit`)**

- Поля: текст, категория (один выбор), приоритет (один выбор), дата и время (две отдельные части, формат на выходе `YYYY-MM-DDTHH:MM:00` или null), теги через запятую.
- «Сохранить»: `PATCH /tasks/{id}` с этими полями, затем возврат на список. Крестик закрывает без сохранения.
- Шаги сохраняются сразу при действии (`/subtasks`), а не по кнопке «Сохранить».
- «Удалить задачу» работает как удаление со списка (то же уведомление с отменой).

**Создание (`NewTask`)**

- Одно поле: текст уходит в `POST /tasks/parse`. Микрофон (Web Speech API) скрывается, если браузер его не поддерживает.
- После успеха: закрыть экран, показать «Добавлено задач: N», выбрать день первой созданной задачи.

**Фильтры (`Filters`)**

- Вид: Активные или Архив. Категория: Все, Study, Work, Personal, UniMe. Приоритет: Все, High, Mid, Low. Подписи на английском, как в текущем приложении.
- «Показать» применяет фильтры и закрывает экран. «Сбросить» возвращает всё в «Все» и «Активные». Когда любой фильтр включён, на кнопке фильтров в верхней панели появляется точка 8 px цвета `--accent` (в макете не нарисована).

**Календарь (`Calendar`)**

- Месяц с понедельника. В клетке число и количество задач. Тап выбирает день, под сеткой компактные строки задач.
- Стрелки перелистывают месяц. Дни соседних месяцев не нажимаются.

**Заметки (`Notes`)**

- Те же операции, что сейчас на сайте: создание, редактирование на месте, удаление с отменой 5 с, голосовой ввод. Кнопка «+» на этой вкладке фокусирует поле новой заметки.

**Архив (`Archive`)**

- Задачи в статусе Done, новые сверху. «Вернуть» делает статус To Do и убирает строку из архива.

**Меню (`Menu`)**

- Статистика: активные задачи и задачи с высоким приоритетом (как сейчас в боковой панели).
- «Архив» открывает `Archive`, «Экспорт CSV» вызывает `downloadCSV`, «Печать / PDF» вызывает `openPrintView`.
- Статусы из `setBackendStatus` и `checkGoogleStatus`. Если Google не подключён: вместо точки нейтральный кружок и ссылка «Подключить Google Calendar» на `/google/auth`. Если backend недоступен: точка цвета `--danger` и текст «Backend недоступен».

**Поиск (`Search`)**

- Подстрока без учёта регистра по названию и тегам всех задач (кроме удалённых). Результаты по дате по возрастанию, в строке показывается дата и время.
- Совпадение подсвечивается фоном `rgba(255,255,255,0.75)`. Число: «Найдено 2 задачи». Пусто: «Ничего не найдено по «…»».

## 6. Правила данных (не нарушать)

- Дедлайн это «голые» часы. Не использовать `new Date(isoString)` для показа, только `parseNaiveDeadline`.
- Категории: `Study | Work | Personal | UniMe`. Приоритеты: `High | Mid | Low`. Статусы: `To Do | In Progress | Done`.
- Русские формы числительных: задача / задачи / задач (есть функция `plural` в макетах).
- Все счётчики считаются на клиенте из уже загруженных задач, новых запросов не нужно.

## 8. Крайние случаи

| Ситуация | Поведение |
|---|---|
| Длинное название | Переносится на несколько строк в списке; в календаре компактные строки до 2 строк, дальше многоточие |
| Много задач в дне | Список прокручивается, нижняя панель остаётся на месте |
| Много тегов | Переносятся на следующую строку |
| Нет задач | «На этот день задач нет» (список), «В архиве пока пусто» (архив), «Заметок пока нет» (заметки) |
| Загрузка | Не нарисована: показывать 3 светлых блока-заглушки со слабой пульсацией. Бесплатный сервер на Render просыпается до минуты, поэтому после 5 секунд добавить подпись «Сервер просыпается, это может занять до минуты» |
| Ошибка сети | Тост «Не удалось … » как сейчас на сайте, статус в меню `--danger` |
| Просроченные задачи | **Не нарисовано, решение в разделе 12** |

## 10. Доступность

- Порядок фокуса: верхняя панель, заголовок, полоса дней, список, нижняя панель, кнопка «+».
- Все иконочные кнопки имеют `aria-label` (в макетах они уже прописаны, перенеси).
- `aria-pressed` у чипов фильтров, `aria-expanded` у шеврона, `role="status"` у уведомления.
- Цвет не единственный признак: у каждой строки подписана категория, у приоритета есть скрытый текст.
- Свайп не единственный способ: «Изменить» доступно по тапу на строку, «Удалить» есть на экране изменения.
- На ноутбуке: Esc закрывает меню и экраны-модалки, Enter в поле шага добавляет шаг.
- Размер всех нажимаемых элементов не меньше 44 × 44.

## 11. Порядок работ

1. Токены и базовые стили, подключить шрифты: `Onest:wght@400;500;600` и `Unbounded:wght@500;600` из Google Fonts. После подключения убедиться по скриншоту, что кириллица рисуется этими шрифтами.
2. Нижняя панель, верхняя панель и экран `Main` с полосой дней.
3. `Edit`, `NewTask`, удаление с уведомлением, свайп.
4. `Filters`, `Menu`, `Archive`.
5. `Calendar`.
6. `Notes`.
7. `Search`.
8. Полировка: пустые состояния, загрузка, ошибки, анимации.

Проверка после каждого шага: `node --check` для скрипта, скриншоты в 390 × 844 и 360 × 740 (можно через Playwright) и сравнение с макетами. Деплой в `main` только после подтверждения владельца.

## 12. Открытые вопросы (решает владелец)

1. **Ноутбук.** Мой вариант по умолчанию: тот же интерфейс одной колонкой шириной 480 px по центру, нижняя панель внизу колонки. Альтернатива: сохранить старый тёмный интерфейс на широких экранах. Нужно выбрать.
2. **Просроченные задачи.** В схеме «по дням» они остались бы на прошлых датах и потерялись бы. Предложение: чип «Просрочено» в начале полосы, виден только если есть такие задачи; число в нём цвета `--danger`; внутри строки с красной подписью даты. Не нарисовано.
3. **Область поиска.** Только задачи, как в макете, или ещё заметки.

### Решения владельца (6 октября 2026)

1. Ноутбук: тот же интерфейс одной колонкой 480 px по центру, нижняя панель внизу колонки. Старый тёмный интерфейс не сохраняем.
