Privacy Policy

JulYera Agent is a personal task-management tool used by its developer only.

Data we handle

Tasks, notes and subtasks entered by the user are stored in a private database (Supabase). Voice messages are transcribed and text is parsed by third-party AI services (Groq) solely to create tasks.

Google user data

If the user connects Google Calendar, the app requests access to calendar events (scope calendar.events) only to create, update and delete events that correspond to the user's own tasks. Google data is not shared with third parties, not sold, and not used for advertising or AI model training.

Retention and deletion

Data is kept until the user deletes it. Access can be revoked at any time at myaccount.google.com/permissions.
